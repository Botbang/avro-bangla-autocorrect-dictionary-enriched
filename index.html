The project foundation

Every expansion should have a reliable point of reference.

This project’s systematic enrichment follows the second-edition government reference volume containing “সরকারি কাজে প্রমিত বাংলা ব্যবহারের নিয়ম” and “সরকারি কাজে ব্যবহারিক বাংলা”.

01
Transparent source material

The exact 445-page volume used for the project is included in the repository so the enrichment work can be reviewed and reproduced.

02
OCR with visual verification

The book uses a legacy ANSI Bangla font. Embedded text is unreliable, so entries are extracted visually and checked against the rendered pages.

Installation

From download
to typing in three steps.

Use Avro Keyboard’s own import screen. Your existing application handles the dictionary installation.

  1. Step 01

    Open the autocorrect editor

    Right-click the Avro icon, then choose Tools → Avro Phonetic Options → Edit/Import Auto Correct Entries.

  2. Step 02

    Enable the helpful options

    Turn on Dictionary mode is default in suggestion and Enable Auto Correct.

    ✓Dictionary mode is default in suggestion
    ✓Enable Auto Correct
  3. Step 03

    Import and type

    Select Import, choose the downloaded autodict.dct file, and confirm.
